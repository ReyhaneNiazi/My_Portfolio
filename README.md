🔗 **Live Demo:** [https://reyhaneniazi.github.io/My_Portfolio/](https://reyhaneniazi.github.io/My_Portfolio/)

## Overview

This repository contains my personal developer portfolio, showcasing selected web development projects, technical skills, and professional experience.
The portfolio is designed with a focus on clean typography, modern aesthetics, balanced visual contrast, and accessible user interactions. It aims to provide a simple and engaging experience while highlighting my development journey, technical expertise, and the projects I have worked on.


## Key Features

- **Semantic & Clean Architecture:** Built entirely with semantic HTML5 elements for optimal accessibility and structure.
- **Custom Modern CSS:** Fluid typography, CSS Grid & Flexbox, custom CSS variables, and bespoke dark color palette.
- **Micro-interactions:** Lightweight keyframe animations, hover states, and smooth navigation.
- **Zero Runtime Dependencies:** High-performance, fast loading times, and minimal footprint.

## Built With

- **Markup:** HTML5 (Semantic & Accessible)
- **Styling:** Modern CSS3 (Grid, Flexbox, Custom Properties)
- **Typography:** DM Mono & Manrope (Google Fonts)
- **Deployment:** GitHub Pages & GitHub Actions
